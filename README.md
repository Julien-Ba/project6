# FishEye

🔗 [Live Demo](https://julien-ba.github.io/project6/)

## Description

This project was developed as part of the OpenClassrooms Web Developer program.
FishEye is a platform for photographers, focusing on JavaScript design patterns and accessibility.

## Project Goals

-   Create a modular JavaScript architecture
-   Implement accessible web design
-   Handle data using JSON
-   Build reusable UI components
-   Ensure keyboard navigation support

## Technical Features

-   JavaScript Architecture:
    -   Factory Pattern for media objects
    -   Observer Pattern for likes/sorting
    -   Modular component structure
    -   Dynamic data handling with JSON
-   UI Components:
    -   Contact form modal
    -   Custom lightbox gallery
    -   Advanced filtering system
    -   Like/sort functionality
-   Accessibility:
    -   ARIA landmarks and labels
    -   Keyboard navigation
    -   Screen reader compatibility
    -   Focus management
